# 📚 Nana's Library

*Ma petite bibliothèque* ☕️🍂

我的個人閱讀紀錄網站：讀過的書、讀完的日期，和當時的心得。

- 🌐 網站：https://yichen940827.github.io/Nana-s-Library/
- 🤖 給 AI 的專案規則：[CLAUDE.md](CLAUDE.md)

## 📖 這個專案在做什麼

我習慣把讀書心得寫在 Mac 的備忘錄裡。這個專案把備忘錄裡的心得、書單，整理成一個像小書店一樣的網站：

- 🏠 **首頁**：立體書架放讀完的書（可以依分類篩選、統計今年讀了幾本）；右上角的「Up next」按鈕會從側邊滑出還沒讀的書單
- 📕 **書頁**：每本讀完的書一頁，有書皮、書籍資料、心得（Little thoughts 🖋️）、喜歡的句子（Lines I love 🔖）；知識型的書另外有重點筆記（Notes to self 📒）
- 🎨 **風格**：法式、秋天、簡約；酒紅與奶油色，心得寫在方格紙上

✍️ 心得一律保留我在備忘錄裡的原文，AI 只負責整理和排版，不代寫、不改寫。

## ✨ 怎麼繼續新增內容

這個專案的重點是 `CLAUDE.md`：它把「怎麼新增一本書」寫成固定規則，讓 AI 讀完就能照同一套方式繼續做。

新增一本書時，我只要：

1. 📝 在備忘錄「Nana's Library」資料夾寫一則心得（標題是書名，加上讀完日期）
2. 📷 把書皮照片放進專案資料夾（檔名用中文書名）
3. 💬 跟 AI 說「我讀完《○○》了」

AI 會照 `CLAUDE.md` 自動完成：

| 步驟 | 規則在哪 |
|---|---|
| 📥 讀取備忘錄的心得與書單 | 第 3 節 |
| 🔍 查作者、原著、出版日期，並附上來源 | 第 3.6 節 |
| 🖼️ 處理書皮照片（裁成正面封面、保留原圖） | 第 3.5 節 |
| 🧩 套用書頁與書架的 HTML 模板 | 第 4、5 節 |
| 🎨 照網站風格排版 | 第 6 節 |
| ✅ 檢查心得與備忘錄原文完全一致 | 第 7、9 節 |
| 🚀 給我確認後上傳 GitHub | 第 8 節 |

其他常用的指令：「幫我更新 Nana's Library」、「我更新書單了」、「幫我做今年的閱讀回顧」，流程都寫在 `CLAUDE.md` 第 8 節。

## 🗂️ 檔案結構

```
├── CLAUDE.md      # 給 AI 的專案規則
├── README.md      # 本文件
├── index.html     # 首頁
├── style.css      # 全站樣式
├── script.js      # 分類篩選、今年本數、翻書動畫
├── books/         # 每本讀完的書一頁
├── notes/         # 每本書的資料與心得備份
├── images/        # 書皮照片（originals/ 是原始照片）
└── tools/         # 書皮照片處理工具（只在我的 Mac 上使用）
```

## 🛠️ 使用的技術

純 HTML、CSS、JavaScript，沒有框架也不需要建置，直接用 GitHub Pages 發布。字體使用 Google Fonts 的 Playfair Display、Noto Serif TC、LXGW WenKai TC。
